# Real-Time Chat Application

A production-ready real-time chat app built with React, Node.js, Express, MongoDB, and Socket.IO. Features include:

- JWT-based authentication
- Real-time messaging with Socket.IO
- Persistent chat history in MongoDB
- Online users list
- Emoji picker integration
- Responsive, clean UI

---

## 🚀 Features

- **Login/Register**: Secure authentication using JWT and bcrypt
- **Chat**: Send and receive messages in real time
- **Emoji Picker**: Insert emojis using `emoji-picker-react`
- **Online Users**: Shows currently connected users
- **Persistent Messages**: Messages stored in MongoDB
- **Token Persistence**: Remains logged in after page refresh

---

## 📦 Tech Stack

- **Frontend:** React, HTML, CSS, JavaScript
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Real-Time:** Socket.IO
- **Security:** JWT, bcrypt
